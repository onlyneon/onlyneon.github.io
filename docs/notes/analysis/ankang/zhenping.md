## 企业注册使用平台状况分析

2. 7月集中注册7家  
开通银企共计4家，其中 镇坪县尚竹居民宿合伙企业（普通合伙），镇坪县智辉云建筑有限公司使用过银企对账功能（使用银企办理过相关业务）镇坪县永禾源农业发展科技有限公司、镇坪丰禾私房菜馆（个体工商户）仅注册未使用，其余模块所有企业均为未使用。
其余3家企业仅注册未使用相关服务，及其他模块功能。  

3. 结论：  
8家企业目前使用过相关功能的企业有2家，其余5家有3家注册了银企但未使用，另外2家仅注册无相关业务数据。  

原因：行社达成企业注册数量，联系企业注册，但企业实际是否日常使用未进行宣传或跟进
